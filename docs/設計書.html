1このアプリは何をするもの？

このアプリは、鯨唄「祝いめでた」を独りで練習するための道具です。先生の唄声（お手本）と、自分のスマホのマイクで拾った声を、同時にグラフの上に重ねて表示します。 録音が終わると、カラオケの採点機能のように点数とランクが出ます。

カラオケボックスの採点機能を思い浮かべてください。あの機械は、あなたの声の高さや長さを、曲のお手本と比べて点数をつけていますね。 このアプリも同じ考え方で、「先生の声の高さの動き」と「あなたの声の高さの動き」を比べて、どれくらい似ているかを点数にしています。 違うのは、鯨唄には楽譜（決まった音程）がないので、「正解の音」ではなく「先生の節回しの形」に近いかどうかで採点するところです。

スマホでもパソコンでも、インターネットにつながなくても動きます。先生の音源（MP3）はアプリの中にあらかじめ埋め込まれているためです（くわしくは第2章）。

2アプリの中身はどうなっている？

アプリは大きく5つの部品でできています。それぞれの役割を図にすると、次のようになります。

① 曲データ
先生の唄声（音声を文字の列にしたもの）と歌詞。曲を増やすときはここを追加する。
↓
② 音の解析
先生の声・自分の声の「高さ」を読み取る仕組み（第3章）。
↓
③ 画面
グラフ・ボタン・メーターなど、目に見える部分すべて。
↓
④ 採点
録音が終わったあと、4つの項目を計算して点数にする（第4章）。
↓
⑤ 記録
練習した日付と点数を、スマホ本体に保存しておく（次にアプリを開いても消えない）。
ここが大事なところ: ①〜⑤の矢印は「一方通行」です。たとえば④の採点の仕組みが②の音の解析の中身を勝手に書き換えたりはしません。 それぞれの部品が自分の持ち場だけをきちんと担当しているので、「採点のルールだけ直したい」「曲だけ増やしたい」というお願いを、他の部分を壊さずにやりやすくなっています。

「base64（びーろくよん）」って何？

先生のMP3の音声ファイルは、アプリの中では「base64（びーろくよん）」という形の、とても長い文字の列として保存されています。

写真を点字に置き換えるようなイメージです。点字にすれば紙の上の文字と同じ扱いで持ち運べますね。 base64も同じで、音声という「音」のデータを、アプリ（プログラムの文章）の中に一緒に書き込める「文字」の形に変換したものです。 アプリを開くときに、この文字の列をもう一度「音」に戻して再生しています。

この仕組みのおかげで、MP3ファイルを別に持ち歩かなくても、アプリのファイル1つだけでお手本の音声ごと持ち運べます。だからインターネットがない場所でも使えるのです。

3声の高さをどうやって測っている？

アプリは「自己相関法（じこそうかんほう）」という方法で、声の高さ（音程）を測っています。

縄跳びの縄を思い浮かべてください。声の波（音の振動）を紙に描いたグラフだとすると、そのグラフをコピーしてもう1枚重ね、少しだけ横にずらしていきます。 ずらす幅を変えながら「いちばんぴったり波の形が重なる」ところを探すと、その「ずらした幅」が、声が1回振動するのにかかった時間にあたります。 振動が速い（ずらす幅が短い）ほど声は高く、遅い（ずらす幅が長い）ほど声は低い、という関係になっています。

声を約23ミリ秒ごと（1秒間に約43回）に細かく区切って、区切りごとにこの測定をくり返しています。これによって、声の高さが時間とともにどう動いているかを、なめらかな線としてグラフに描けるようになっています。

  • 声が小さすぎる（無音に近い）ときは「測れなかった」として扱われ、グラフの線は途切れます。
  • 人の声として不自然に低すぎたり高すぎたりする音（40Hz未満、3000Hzを超える音）も無視します。

先生の音声はあらかじめこの方法で全体を解析しておき、自分の声は録音しながらリアルタイムで同じ方法で測定して、2つの線を同時にグラフへ流します。

4採点の仕組み

録音が終わると、次の4つの項目を計算して、重みをつけて合計し、0〜100点の総合点にします。

項目重み何を見ているか
節回しの近さ40%先生の声の高さの動きと、自分の声の高さの動きが、どれくらい似ているか
音量・強弱20%声がしっかりした大きさで出ているか
継続・伸び20%声を止めずに長く出し続けられているか（目安30秒）
声の安定20%声の高さが急にガクガク揺れていないか

合計点に応じて、次のランクが表示されます。

ランク点数の目安表示されるメッセージ
S90点〜完璧！先生の節回しそのまま！
A78〜89点上手い！節回しがよく合っている
B65〜77点だいぶ近づいてきた！あと少し
C50〜64点練習を重ねると形が見えてくる
D〜49点今日の第一歩！毎日少しずつ
鯨唄には決まった正解の音程がないので、「音を外した・外していない」を厳しく見る採点ではありません。あくまで先生の声の動き方の「形」にどれだけ近づけたかを見る、練習の目安としてお使いください。

5新しい鯨唄（曲）を増やしたいとき

「祝いめでた」以外の鯨唄も練習できるようにしたい場合、先生の新しいMP3音源と歌詞の文章があれば、Claudeにお願いするだけで追加できます。ご自身でプログラムのファイルをいじる必要はありません。

用意していただくものは次の2つです。

  • 先生の唄声のMP3ファイル
  • 歌詞の文章（できれば「何秒あたりでどの歌詞が流れるか」の目安。分からなければ「あとで調整する」でも大丈夫です）
「〇〇（曲名）」という鯨唄を新しく追加してください。 MP3ファイルはこちらです（ファイルを添付、または保存場所を伝える）。 先生の表記は「〇〇保存会」でお願いします。 歌詞は次の通りです： （歌詞の文章を貼り付ける） 何秒あたりで各行が流れるかはまだ分からないので、 だいたいで仮に入れておいて、あとで一緒に調整させてください。

お願いすると、Claudeが曲のデータをアプリの中に追加し、曲を選ぶメニューにも自動で反映されます。歌詞が流れるタイミングがずれていると感じたら、 「12秒のところの歌詞を15秒に直してください」のように、気づいたところをそのつど伝えていただければ微調整できます。

6アプリを更新して使うまでの流れ

アプリの中身（採点のルールや画面のデザインなど）を直したあとは、「ビルド」という作業をして、スマホで開ける1つのファイルに組み立て直す必要があります。

料理でいうと、下ごしらえした材料（プログラムの部品たち）を、最後にひとつのお弁当箱（1つのHTMLファイル）に詰め込み直す作業です。 詰め直さないと、スマホというお弁当箱を持っていく先（Google Drive経由での転送）に持っていけません。
  1. Claudeに「ビルドしてください」とお願いする、または呪文（コマンド）npm run build を実行してもらう。
  2. すると dist というフォルダの中に index.html という1つのファイルができます。これが新しいアプリ本体です（先生のMP3も中に埋め込み済み）。
  3. この dist/index.html を、いつもどおりGoogle Driveに置いて、スマホ側でGoogle Driveアプリから開けば、更新されたアプリが使えます。
呪文について: npm run build のような英数字の並びは、Claudeやパソコンに「これをやって」と伝えるための決まり文句（呪文）です。 意味を覚える必要はありません。「アプリを更新してスマホで使えるファイルにしてください」とClaudeに日本語でお願いすれば、代わりに呪文を実行してくれます。

7困ったときのQ&A

マイクの許可を聞かれたけれど、どうすればいい？
「マイクへのアクセスを許可しますか」というポップアップが出たら、「許可」または「Allow」を選んでください。許可しないと、自分の声を測定できず録音ボタンが動きません。誤って「許可しない」を選んでしまった場合は、スマホの「設定」アプリからブラウザ（SafariやChrome）のマイク許可を後から変更できます。
iPhoneで音が出ない・声が出ない
iPhoneのマナーモード（横のスイッチ）がオンになっていると音が鳴らないことがあります。まずマナーモードを確認してください。それでも鳴らない場合は、一度ページを閉じて開き直す、またはSafariの「履歴とWebサイトデータを消去」を試すと直ることがあります。
「先生の音程を解析する」のあと、なかなか進まない
先生の音源（3分ほど）を細かく読み取っているため、機種によっては数秒〜十数秒かかります。進み具合（%）が表示されている間は正常に動いていますので、そのままお待ちください。
採点の点数がいつも低い気がする
声が小さいと「音量」の項目が低くなりやすく、途中で声が途切れると「継続・伸び」も下がります。マイクに近い位置で、最後まで声を止めずに歌ってみてください。それでも気になる場合は、採点の重みや基準をClaudeに相談して調整できます。
練習の記録が消えてしまった
練習記録はスマホ（ブラウザ）の中に保存されています。ブラウザの「閲覧履歴・データを消去」を行うと、この記録も一緒に消えてしまうことがあります。消去する前にバックアップを取りたい場合はClaudeに相談してください。
アプリの見た目や採点のルールを変えたい
「ここをこう変えてほしい」と日本語でClaudeにお願いすれば大丈夫です。たとえば「採点の甘さを少し上げてほしい」「歌詞の文字をもう少し大きくしてほしい」のように、具体的にどうしたいかを伝えてください。
